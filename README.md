# Catzye

A reference to how manga works — explainers, a glossary, entries for the series
and the people who drew them — arranged not by topic but by **the number each
title reduces to**.

## The filing rule

Every letter carries a digit: A is 1, B is 2, on to I at 9, then the alphabet
starts again. Sum a title's letters and reduce the total until one figure
remains. The master numbers 11, 22 and 33 are never reduced, which is why they
have shelves of their own and why so few texts reach them.

That gives twelve shelves — The Opening, The Pairing, The Telling, The
Structure, The Turn, The Care, The Inquiry, The Ledger, The Closing, The Signal,
The Edifice, The Teaching — and every text on the site lives on one of them.

The shelves are uneven and were left that way. Nothing was moved to balance
them: 2 holds ten texts because a sum reducing to 11 stops at 11 rather than
continuing down.

## Where a number is *not* imposed

Reducing a title is an imposition, and for a manga it usually reduces an English
licensing decision rather than anything the author wrote. Three kinds of number
here were not calculated by us, and where they contradict a title reduction the
entry says so and the figure wins:

- **A work's own figures** — volume count, years serialised, debut year
  (`lib/work-numbers.ts`).
- **画数 and 姓名判断** — the stroke count of a Japanese title, and the five
  figures of Japanese name divination for a creator's native name
  (`lib/strokes.ts`). Pen names are constructed things and stroke count is one
  of the things they are constructed around, so these are the likeliest readings
  on the site to have been intended by their subject.
- **The numbered sets manga invented for itself** — the Four Emperors, the
  Twelve Kizuki, the Gotei 13 (`data/numbered-sets.json`, `/sets`). These are
  filed by their own count rather than by their titles, because a number an
  author chose outranks one this repository calculated.

## How the readings are written

Every text carries a reading: a line above it, a full reading below. **None was
written by hand and none was generated by a model.** They are composed from each
title's own arithmetic by `lib/numerologize.ts`, with phrasing selected from an
FNV-1a hash of the slug — so the figures quoted are always real, and rebuilding
produces the same words again.

## Running it

```bash
npm install
npm run dev
```

There is no database. `data/*.json` is the published edition and `lib/db.ts`
reads it directly; the Prisma client is kept only for the `/admin` write path,
and the site is fully functional with no `DATABASE_URL` set.

After editing anything in `data/`, regenerate the readings and commit the
result:

```bash
npx tsx scripts/numerologize.ts          # rewrite in place
npx tsx scripts/numerologize.ts --check  # report only, write nothing
```

It is idempotent — HTML bodies carry markers it strips before re-injecting, and
short text fields keep their original in a `…Source` companion — so running it
twice is the same as running it once.

## Layout

| Path | What it holds |
| --- | --- |
| `lib/numerology.ts` | The Pythagorean and Chaldean engine, and the per-number profiles. |
| `lib/number-groups.ts` | The twelve shelves and `titleValue()`, the one filing rule. |
| `lib/numerologize.ts` | The prose composer. Deterministic, no model. |
| `lib/strokes.ts` | 画数 stroke tables and 姓名判断. Refuses to guess. |
| `lib/numbered-sets.ts` | Sets filed by their own count. |
| `lib/shelves.ts` | One index across every kind of text on the site. |
| `scripts/numerologize.ts` | The publishing pipeline. |
| `data/*.json` | The edition. |
